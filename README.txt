YUKTA COSMETICS — COMPLETE WEBSITE ASSIGNMENT PACKAGE
=====================================================

WHAT IS INCLUDED
----------------
1. index.html  - Complete website content and semantic page structure.
2. style.css   - Brand styling, responsive layouts, accessible focus states and reduced-motion support.
3. script.js   - Mobile navigation, working demo shopping bag, cart subtotal, toast feedback and sample newsletter form.
4. ASSIGNMENT_REPORT.md - Rubric mapping, business purpose, technical plan, testing, maintenance and presentation notes.
5. README.txt  - These instructions.

HOW TO OPEN
-----------
1. Download and extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. It opens in a modern web browser. No installation or local server is required.

IMPORTANT
---------
Yukta Cosmetics and Dew Drop Lip Gloss are fictional student project concepts.
Shade names, descriptions and ₹499 prices are illustrative.
The cart is a front-end demonstration. There is no checkout, payment gateway, inventory, customer account or real order processing.
The newsletter form only demonstrates client-side validation and a confirmation message. It does not transmit or store an email address.
The website is not deployed and no domain has been registered. Hosting options and launch requirements are explained in the website and assignment report.
Google Fonts are loaded from Google when an internet connection is available; system font fallbacks are included.
